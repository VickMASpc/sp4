# ADS na SPTech — guia simples

Página estática, mobile-first e GitHub Pages-friendly explicando de forma visual:

- progressão dos 5 semestres;
- horários de aula;
- mensalidade e bolsa-estágio;
- como funciona o estágio integrado;
- empresas parceiras;
- perguntas comuns de aluno e família;
- simulador simples de entrada x mensalidade.

A aplicação inteira está em `index.html`, sem framework ou dependências externas.
